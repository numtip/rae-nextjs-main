# RAE fal.ai Generation Rules

**RC4.3 Creative Governance Foundation** · Rules and constraints for AI-generated video/motion assets via fal.ai  
**Status:** Approved for RC4.3 · **Generation NOT yet started** (deferred to RC4.4+)  
**Authority:** This document governs all fal.ai video generation for RAE website assets. No generated video may ship without compliance.

---

## Scope

fal.ai is the designated AI video generation platform for RAE motion assets. This document defines what is allowed, what is forbidden, and what technical constraints apply to all generated outputs.

**Current state (RC4.3):** Rules defined only. No API calls made. No assets generated. No credits consumed.

---

## Generation Rules

### Duration

| Rule | Value |
|------|-------|
| Minimum duration | 5 seconds |
| Maximum duration | 8 seconds |
| Target duration | 6–7 seconds (sweet spot for loop quality) |

Rationale: 5–8 seconds provides enough motion for a seamless background loop without excessive file size or generation cost.

### Audio

| Rule | Value |
|------|-------|
| Audio track | **Must be empty/silent** |
| Audio codec | N/A — strip all audio from output |

Rationale: Autoplaying audio is an accessibility violation and terrible UX. RAE website motion is visual-only.

### Text

| Rule | Value |
|------|-------|
| Baked text in video | **Forbidden** |
| Text overlay | Must be HTML/CSS overlay in website code |

Rationale: Text in video cannot be localized (th/en), is not accessible to screen readers, and degrades on compression. All text lives in the DOM.

### Watermarks

| Rule | Value |
|------|-------|
| Watermarks | **Forbidden** |
| Brand logos in video | **Forbidden** |
| "Generated by AI" labels in-frame | **Forbidden** |

Rationale: The RAE logo and any attribution are rendered in the website chrome, not baked into video.

## Technical Requirements

### Loop Safety

| Requirement | Detail |
|-------------|--------|
| Seamless loop | First frame and last frame must be visually identical |
| Loop transition | No visible jump, flash, fade, or color shift |
| Validation | Test 3+ consecutive loops before approval |

### Web Safety

| Requirement | Detail |
|-------------|--------|
| Primary format | WebM (VP9 codec) |
| Fallback format | MP4 (H.264 codec) |
| Color space | sRGB / BT.709 |
| Resolution | 1920×1080 (Full HD) max |
| Frame rate | 24 fps (preferred) or 30 fps max |
| Bitrate target | 1–3 Mbps for WebM VP9 |

### Poster Frame

| Requirement | Detail |
|-------------|--------|
| Required | Every video asset must have a poster frame |
| Format | WebP or JPEG |
| Ratio | Must match video (16:9) |
| Source | Extracted from first frame of video |
| File size | ≤ 80 KB |

## Prompt Constraints

### Allowed Subjects

- Maejo campus landscapes and greenhouses
- Agricultural fields, crops, soil (gentle motion)
- Laboratory environments (subtle equipment glow)
- Natural light moving across research spaces
- Abstract green/gold gradients with organic movement
- Soft particle drift (pollen, light dust motes — not sci-fi)

### Forbidden Subjects

- Human faces or figures (AI-generated people)
- Text or typography of any kind
- Fast-moving objects or rapid scene changes
- Abstract sci-fi / cyberpunk / gaming environments
- Animals (unless Maejo-specific and documentary style)
- Religious or political imagery
- Any subject outside Maejo/RAE/agriculture context

### Prompt Template

```
[CALM][PREMIUM INSTITUTIONAL] [SUBJECT DESCRIPTION]
Style: documentary-cinematic, warm natural light, subtle motion
Motion: [slow parallax / soft glow / light sweep / gentle drift]
Color palette: natural greens, warm gold accent only
Duration: 6 seconds, seamless loop
No text, no watermarks, no people, no fast motion
Resolution: 1920x1080, 24fps
```

### Example Prompts


## Post-Generation Pipeline (RC4.4+)

Every fal.ai output must pass through this pipeline before repo integration:

```
fal.ai generation
    ↓ download raw output
rae-motion-lab/generated/motion/ (raw draft)
    ↓ strip audio (ffmpeg)
    ↓ encode WebM VP9 (ffmpeg)
    ↓ encode MP4 H.264 fallback (ffmpeg)
    ↓ extract poster frame (ffmpeg)
rae-motion-lab/compressed/ (optimized)
    ↓ QA checklist (MOTION_QA_CHECKLIST.md)
rae-motion-lab/approved/ (QA-passed)
    ↓ commit
rae-nextjs-main/public/assets/motion/ (repo)
```

| Batch limit | Max 5 assets per sprint without explicit approval |

---

## QA Gate (Before Integration)

Every fal.ai generated asset MUST pass [MOTION_QA_CHECKLIST.md](./MOTION_QA_CHECKLIST.md) before status changes from `review` → `approved`.

Additional fal.ai-specific checks:

- [ ] Output matches prompt intent (no AI hallucination drift)
- [ ] No unintended artifacts (morphing, distortion, uncanny movement)
- [ ] Color palette within brand boundaries
- [ ] No AI-generated human figures or faces
- [ ] Duration within 5–8 second range
- [ ] Loop seam imperceptible after 3+ cycles

---

## Prohibited

- Generating assets without prompt review
- Integrating assets that skip the compression pipeline
- Using generated assets with baked text
- Exceeding iteration or batch limits without approval
- Generating assets for sections not in scope (e.g., inner pages before RC4.5+)
- Using fal.ai for image generation (only motion/video)
