### Thai Copy

```
ศูนย์เอกสารและแหล่งทุน
RAE ให้บริการดาวน์โหลดเอกสาร แบบฟอร์ม คู่มือ และเอกสารวิชาการ
พร้อมเชื่อมโยงนักวิจัยกับแหล่งทุนจากสำนักงานพัฒนาการวิจัยการเกษตร (สวก./ARDA)
ทั้งกองทุน Strategic Fund (SF) และ Research Utilization (RU) สำหรับปีงบประมาณ 2570
```

### English Copy

```
Document Center & Funding Access
RAE provides downloadable documents including forms, guides, and academic publications,
and connects researchers to ARDA (Agricultural Research Development Agency) funding,
including Strategic Fund (SF) and Research Utilization (RU) programs for fiscal year 2570.
```

### Document Storage Policy (MANDATORY — Display Prominently)

> ⚠️ **เว็บไซต์ RAE ไม่ใช่ระบบจัดเก็บเอกสาร** เว็บไซต์ทำหน้าที่เป็น Document Registry / Discovery Layer เท่านั้น ไฟล์ต้นฉบับทั้งหมดจัดเก็บใน Microsoft 365 / SharePoint / OneDrive

> ⚠️ **The RAE website is NOT a document management system.** It functions as a Document Registry / Discovery Layer only. All master files are stored in Microsoft 365 / SharePoint / OneDrive. No master files are stored on the VPS.

### Design Intent
Split layout: left side Document Registry cards, right side Funding cards. Storage policy notice as an info banner at the top of this section. All download links must point to SharePoint/OneDrive — never to local VPS paths.

### CTA Intent
"Access Documents" → SharePoint link | "View Funding" → link to research-services page with funding section.

- KB-0011 (Document Downloads, Storage Policy), KB-0041 (ARDA SF), KB-0042 (ARDA RU)
- File: `04_Documents_and_Funding.md`
